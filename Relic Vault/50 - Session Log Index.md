# Session Log Index

Use this index to keep a short Obsidian-linked trail of Relic development sessions.

## Log Rules

- Add one log at session close under `Relic Vault/Session Logs/`.
- Link each log back to [[50 - Session Log Index]].
- Link the main vault notes and code files touched when useful.
- Keep logs concise: accomplished, changed, verified, follow-ups.
- Do not record secrets, keys, tokens, or private environment values.
