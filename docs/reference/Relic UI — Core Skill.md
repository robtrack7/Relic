# Relic UI

Use this skill whenever making user-facing design or interaction decisions.

## North star

**Relic is a beautiful private desk where a living fictional world has accumulated.**

The world is primary. The interface should feel calm, spatial, tactile, intelligent, and authored — never like a generic productivity app.

**Visual shorthand:**\
warm editorial modernism × archival research desk × spatial knowledge canvas × quiet fictional atmosphere

## Core laws

1. **The world stays present.** Fictional material should feel like artifacts in a world, not database records.
2. **The canvas is a view, not the database.** Spatial manipulation changes composition, never semantic truth.
3. **Selection deepens; it does not leave.** Prefer Focus and contextual controls over conventional detail-page navigation.
4. **Direct manipulation first.** Prefer drag, arrange, select, group, connect, stack, annotate, and resize over forms and modal configuration.
5. **Complexity appears when needed.** Use semantic zoom, Focus, search, spatial grouping, and progressive disclosure instead of permanent chrome.
6. **AI acts through the world.** The Librarian understands current context and acts in the natural medium of the answer. Chat is a carriage, not the product.
7. **Mystery comes from the fiction.** Do not manufacture atmosphere with fantasy UI decoration.

## Visual direction

- Warm ivory / mineral-paper surfaces.
- Near-black ink and charcoal.
- Restrained **Relic Orange** as the primary active signal; start near `#ED6C34` and tune in context.
- Modern sans for UI and titles.
- Serif selectively for narrative material and Stage.
- Mono sparingly for provenance, dates, sources, and system metadata.
- Thin rules, precise alignment, generous negative space.
- Cards may vary by content; do not force one universal template.
- Tactile, matte, restrained depth. Never skeuomorphic.
- Strong imagery when it makes the fictional world tangible.

### Icons

Use **Phosphor** as the default placeholder/system family.

- Regular for primary controls.
- Light for quieter secondary UI.
- Wrap important icons semantically so Relic-specific marks can replace them later.

## Interaction quality

Canvas feel matters:

- precise pan;
- cursor-anchored zoom;
- controlled inertia;
- immediate interruption;
- excellent trackpad behaviour;
- continuity through Focus and view changes.
- tactile actions
- animated outcomes

## Responsive rule

Desktop/tablet exploit spatial interaction.

Narrow screens preserve **workflow parity, not canvas parity**. Use stacks and focused views rather than shrinking the canvas into an unusable miniature.

## Decision test

When several solutions work, prefer the one that:

1. makes the fictional world more present;
2. reduces software chrome;
3. preserves spatial/contextual continuity;
4. makes the direct action obvious;
5. leaves room for the interface to evolve.

This establishes direction, not a frozen design system.

Read `references/visual-language.md` only when making detailed Card, spatial, Librarian, visual, density, or Stage decisions.
