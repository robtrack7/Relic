# FOC-BLK-014 — Sources & Provenance Block

Parent: [[SYS-06 — Focus & Shared Focus Blocks]]

## Purpose

Provides the deep evidence/origin view behind focused World Object material.

## Anatomy

May show:
- supporting Sources;
- originating Session;
- transcript excerpt;
- imported document;
- GM-authored Source;
- derived/Librarian-assisted origin;
- source count;
- relevant claim-level provenance;
- exact PDF/page/anchor where available.

## Behaviour

Can:
- open Source Focus/viewer;
- jump to PDF page;
- inspect excerpt;
- search within Source;
- open the associated Session;
- ask Librarian with that Source context.

Provenance is available when needed without dominating ordinary Focus reading.

## Boundaries

Source existence does not imply truth.

Authorship does not imply truth.

Permissions must limit displayed Source details to authorized content.

## Relationships

- [[OBJ-SRC — Source Representation Family]] — underlying Sources.
- [[OBJ-008 — Object Provenance Cue]] — compact entry.
- [[MEC-015 — Rules Reference Binding]] — specialized rule-source deep links.

## Handoff

Build **FOC-BLK-014 — Sources & Provenance Block** as the complete traceability/evidence section for Focus.
