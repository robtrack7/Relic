# FOC-BLK-004 — Roleplay Block

Parent: [[SYS-06 — Focus & Shared Focus Blocks]]

## Purpose

Provides the full portrayal-oriented material for Characters or other actor-like World Objects.

## Anatomy

Potential entries:
- personality;
- voice;
- mannerisms;
- tells;
- beliefs/values;
- fears;
- bonds;
- flaws;
- emotional tendencies;
- secrets;
- portrayal guidance.

Only populated/useful fields appear.

## Appearance & behaviour

Feels like actor/GM portrayal notes rather than a clinical personality form.

Can use short labelled snippets, pull-quote treatment, and compact prose.

Sparse Characters should remain visually composed rather than showing many empty categories.

## Relationships

- [[OBJ-CHAR-15 — Character Roleplay Snapshot]] — compact projection.
- [[FOC-008 — Focus Inline Editing]] — direct editing.

## Handoff

Build **FOC-BLK-004 — Roleplay Block** as the full sparse-friendly portrayal section for Character Focus and compatible actor families.
