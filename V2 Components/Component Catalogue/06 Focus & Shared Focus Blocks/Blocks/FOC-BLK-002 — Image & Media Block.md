# FOC-BLK-002 — Image & Media Block

Parent: [[SYS-06 — Focus & Shared Focus Blocks]]

## Purpose

Provides deeper visual/media material than the compact Object Image & Media Lead.

## Anatomy

Can support:
- primary image;
- additional images;
- maps;
- diagrams;
- handouts;
- captions;
- visual Sources;
- source/provenance cues.

Family Focus determines which media forms are relevant.

## Appearance & behaviour

Editorial gallery/contact-sheet behavior rather than a generic file manager.

Images can open larger inspection views.

Media without a visual preview still exposes a clean file/source representation.

The block must remain elegant when only one image exists.

## Relationships

- [[OBJ-006 — Object Image & Media Lead]] — compact primary image.
- [[FOC-BLK-014 — Sources & Provenance Block]] — media evidence/origin.
- Source representation family — underlying media/source identities.

## Handoff

Build **FOC-BLK-002 — Image & Media Block** as the reusable Focus gallery/visual-material section.
