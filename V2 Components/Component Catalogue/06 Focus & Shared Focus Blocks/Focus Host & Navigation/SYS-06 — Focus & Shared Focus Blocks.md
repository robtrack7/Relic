# SYS-06 — Focus & Shared Focus Blocks

Focus is Relic's shared deep-object workspace infrastructure.

The Focus Host is shared. Each World Object family owns its own deliberate Focus composition. Shared Focus Blocks supply reusable semantic sections without creating a universal detail page.

## Core rules

- Focus is not a modal inspector or CRUD detail page.
- Family Focus surfaces remain separately owned components.
- Family Focus owns block order and emphasis.
- Focus Blocks own their own anatomy and editing behavior.
- Focus is locally editable; there is no global Edit mode.
- Historical Focus genuinely resolves temporal state as-of the selected story position.
- Stage and Librarian can remain present around Focus.
- The Librarian receives Focus context through a context bridge; there is no duplicated Librarian Actions block.
- Focus blocks are not automatically card-framed.
- User-reorderable Focus layouts are not part of the initial product.
