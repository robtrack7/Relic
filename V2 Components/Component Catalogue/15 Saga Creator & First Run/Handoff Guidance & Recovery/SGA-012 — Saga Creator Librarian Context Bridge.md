# SGA-012 — Saga Creator Librarian Context Bridge

Parent: [[SYS-15 — Saga Creator & First Run]]

## Purpose

Supplies first-run context to the ordinary Librarian while preserving authority, provenance and human-initiation boundaries.

## Context

May include Saga shell, World, Mechanics Profile, GM-authored premise, imported Sources, current Starting World Change Set, selected proposed object, First Desk, unresolved identity questions and Session 1 seed.

## Origin labels

Maintain explicit **GM-authored / Source-derived / Librarian-generated** distinctions through proposals and settlement.

## Scope

Existing World-scoped canon may ground the new Saga. Sibling Saga-specific canon remains excluded by default.

## Human initiation

No model work merely because the GM opens the Desk/Librarian, stores a Source, selects/moves proposals, switches World, or changes mechanics. Valid triggers include a submitted message, `Build from this`, `Organize into my Saga`, or continuation of that authorized task.
