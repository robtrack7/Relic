# SYS-15 — Saga Creator & First Run

## Purpose

Owns the shortest trustworthy path from no Saga to a useful real Desk and then into Session 1.

## Core law

> **First run is creation, not onboarding.**

The first Saga is real. After minimal identity setup, the GM lands directly on the ordinary Desk. The Desk itself exposes manual creation, existing-material ingestion, Librarian assistance, and Prepare Session 1.

## Flow

`New Saga → minimal Saga/World/mechanics setup → normal Desk → build / bring material / use Librarian → Prepare Session 1`

There is no starting-approach screen, tutorial Saga, dedicated creator Canvas, or creator-specific Librarian.

## Non-negotiables

- Manual creation is first-class.
- Empty Desk helpers never trigger AI.
- Imported material remains Source-backed.
- Assisted creation uses ordinary Proposal Layer + Change Set semantics.
- Generate only enough material to make the premise legible and Session 1 preparable.
- The world is expected to grow through play.
