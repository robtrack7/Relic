# SGA-010 — First-Run Guidance & Learn-by-Doing

Parent: [[SYS-15 — Saga Creator & First Run]]

## Purpose

Provides minimal deterministic guidance while the GM uses their actual Saga.

## Guidance

Prefer empty-state copy, one-time micro-hints, subtle tooltips and self-explanatory labels. Avoid modal tours, tutorial campaigns, completion checklists, and AI-generated onboarding.

## Examples

- `Double-click an object to open Focus.`
- `Connect creates a world Relationship. Compose creates Board-only marks.`
- `Build manually, bring material, or use the Librarian.`

## Dismissal

Hints disappear once they are no longer useful and never block work.
