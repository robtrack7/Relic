# SGA-008 — First Desk Composition

Parent: [[SYS-15 — Saga Creator & First Run]]

## Purpose

Ensures assisted creation produces a meaningful spatial starting point rather than only database records.

## Goals

Foreground central people/places/factions, keep Threads near relevant material, show only useful semantic Relationships, leave breathing room, and avoid diagramming the entire world.

## Reuse

Use ordinary Board, [[BRD-006 — Placement Host]], family Cards, semantic Relationships and [[DSK-029 — Canvas Proposal Layer]]. No creator-only canvas primitives.

## Learning

The First Desk naturally teaches that objects persist beyond Cards, Canvas is composition, Relationships are semantic, Focus is depth, and Librarian acts on the same world.
