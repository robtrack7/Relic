# SGA-006 — Starting World Change Set

Parent: [[SYS-15 — Saga Creator & First Run]]

## Purpose

Groups an assisted starting-world build into one coherent proposed action using Relic's normal trust architecture.

## Contents

May include proposed World Objects, Relationships, initial temporal state, Board Placements/composition, Saga orientation, and Session 1 seed.

## Provenance

Preserve distinctions among **GM-authored**, **Source-derived**, and **Librarian-generated** material even when presented as one package.

## State

Assisted generated material remains proposed until settlement. The GM can edit, remove, rearrange, create additional material manually, or ask Librarian to revise without rebuilding from scratch.
