# DS-FND-SHAPE — Borders Radii & Elevation

## Purpose

Defines the restrained structural language for edges, corners and floating depth. Relic should read as editorial/spatial software, not a stack of generic rounded SaaS cards.

## Roles to establish

Test: subtle separator line; strong/selected boundary; focus ring; base component corner treatment; floating/overlay corner treatment; and a minimal elevation ladder for anchored popovers, menus/dialogs and docked/floating UI.

## Rules

- use borders/lines when they clarify structure; use whitespace when a line adds noise;
- radii should be restrained and systematic;
- elevation communicates layering, not decoration;
- Canvas selection/proposal geometry may deliberately use line treatment rather than card shadow;
- docked Carriages should not look like detached floating modals.

## Storybook / manual test

Validate Cards, fields, menus, popovers, dialogs, Canvas selections, proposal states and Carriages on the real intended backgrounds.
