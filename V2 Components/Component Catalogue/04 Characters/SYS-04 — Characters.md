# SYS-04 — Characters

Character is the reference implementation for rich World Object families. One persistent identity is projected through separately coded spatial, retrieval, preparation, Stage-navigation, temporal, and Focus representations.

## Primary disclosure
`Character Marker → Character Card → Expanded Character Card → Character Focus`

Expanded Character Card uses a narrative front and abbreviated mechanics back.

## Stage rule
There is no duplicate full Stage-side Character card component. Stage Entity Rail uses [[OBJ-CHAR-11 — Character Stage Bubble]]; selecting it navigates to the ordinary Character Card / Expanded Character Card on central Canvas.
