# OBJ-CHAR-17 — Character Knowledge Snapshot

Parent: [[OBJ-CHAR — Character Representation Family]]

## Purpose

Displays a small set of narratively meaningful Character knowledge appropriate to context.

## Knowledge states

Knows, Believes, Suspects, Was told.

## Context filtering

Expanded Card shows only highly useful current knowledge; Prepare shows Session-relevant knowledge; Librarian briefs answer current scene/question; historical contexts use knowledge as-of the selected story position.

## Anatomy

Each entry may include state verb, concise proposition, related object, and source/time only when needed.

## Boundaries

Do not create an exhaustive Character × fact matrix. Unmodeled knowledge remains valid.

## Handoff

Build **OBJ-CHAR-17 — Character Knowledge Snapshot** as the contextual, temporally aware compact knowledge projection.
