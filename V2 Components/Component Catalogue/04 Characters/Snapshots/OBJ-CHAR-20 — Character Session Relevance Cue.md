# OBJ-CHAR-20 — Character Session Relevance Cue

Parent: [[OBJ-CHAR — Character Representation Family]]

## Purpose

Expresses why this Character matters to the active Session. This is Session composition, not Character canon.

## Examples

`Knows the courier route`, `Expected at the Winter Court`, `Likely to confront Mara`, `Has the ledger`, `Opening-scene contact`.

## Used by

Prepare Row/Card, Stage Bubble tooltip/entity rail, and session planning.

## Behaviour

Can be authored manually, suggested by Librarian during Prep, or explicitly generated/pinned during Stage. It does not overwrite Character summary/state unless separately established.

## Handoff

Build **OBJ-CHAR-20 — Character Session Relevance Cue** as the Session-local reason-this-person-matters component.
