# OBJ-CHAR-21 — Character Action Contributions

Parent: [[OBJ-CHAR — Character Representation Family]]

## Purpose

Character-specific actions contributed through [[OBJ-013 — Object Action Contribution Contract]].

## Desk

Focus, Expand/Collapse, Connect, Add to Session. Placement actions remain Desk-owned.

## Focus

Edit Character, add Relationship, add Knowledge/Belief, add to Thread, add Event, archive, open/add Rules Reference, ask Librarian.

## Prepare

Pin/unpin, edit Session Relevance, open Focus, ask Librarian for session-specific ideas.

## Stage

Locate on Stage Canvas, Focus, add to Encounter Flow, open live mechanics, capture Character-related note, and use Librarian naturally in current-scene context.

## Boundaries

No automatic attack resolution, HP deduction, condition automation, or resource expenditure automation.

## Handoff

Implement **OBJ-CHAR-21 — Character Action Contributions** as the Character action set consumed by Desk, Focus, Prepare, and Stage.
