# SET-003 — Appearance & Interface Preferences

Parent: [[SET-001 — Settings Surface & Scope Navigation]]

## Purpose

Owns personal cross-Saga interface preferences without turning Relic into a theme-builder.

## Appearance

Initial choices:
- System;
- Light;
- Dark.

All modes remain expressions of the same Relic design system.

## Accessibility / motion

Where platform support warrants it, this area can later include restrained preferences
such as reduced motion or relevant accessibility controls.

Prefer platform/system defaults wherever possible.

## Explicit exclusions

Do not initially add:
- font selection;
- arbitrary accent/palette editors;
- user-authored themes;
- UI skin marketplace;
- layout-builder settings.

Relic should continue to look like Relic.

## Scope

Personal setting.

Applies across Sagas for the signed-in GM.

## Handoff

Build **SET-003 — Appearance & Interface Preferences** as a small personal preference
surface aligned to the canonical Relic design system.
