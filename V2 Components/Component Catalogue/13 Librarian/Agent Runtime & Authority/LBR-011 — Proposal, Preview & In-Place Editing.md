# LBR-011 — Proposal, Preview & In-Place Editing

Parent: [[SYS-13 — Librarian]]

## Purpose

Shows unsettled Librarian-generated content in the same medium where it would live, avoiding generic draft queues.

## Canvas proposals

Use [[DSK-029 — Canvas Proposal Layer]] for proposed cards, Relationships, or layouts.

## Focus / text proposals

Show semantic current/proposed state inline.

## Prepare / Stage / Settlement

Proposed Beats appear in the Scene stack; proposed Session material appears in context; Settlement Story Changes update directly in Settlement surfaces.

## Actions

Typically Apply, Edit, Dismiss, or contextual settlement equivalents.

## Maturity boundary

Proposal state is not Pencil maturity. Pencil/Ink describes maturity; proposal/settled describes authority/truth.
