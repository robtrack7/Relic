# SYS-10 — Sessions & Prepare

## Purpose

Owns Session lifecycle, the durable Sessions destination, and the Prepare workspace state that bridges the living world into live play.

## Core product model

`Sessions → Prepare Workspace State → Stage → Review → changed world`

Sessions is the durable destination.

Prepare is not a detached form page. It is:

`Prepare Carriage | Prep Canvas Lens | Librarian`

Stage later evolves that same grammar into:

`Stage Carriage | Stage Canvas | Librarian`

## Core rules

- Session is a lifecycle/container, not a World Object.
- Session lifecycle remains Planned → Ready → In Progress → Ended.
- Review/pipeline status is separate.
- Prepare is a workspace state.
- Prepare Carriage provides Session structure.
- Prep Canvas Lens foregrounds relevant world material without changing identity.
- The normal Canvas tool set remains available.
- Scenes/Beats are lightweight Session-local composition, not persistent World Objects.
- Stage consumes the same Scene/Beat structure.
- Prepared material can include persistent identity references + Session-local relevance and intentionally Session-scoped Session Instances.
- No automatic Session Board is created.
- Carry-Forward prioritizes approved/settled state.
- Librarian is a core operating layer, not a separate Prep AI feature.
- Ready does not lock Prep.
- Sparse Sessions can enter Stage with warnings rather than hard blocking.
- Prepare can seed lightweight Scene participant rosters without becoming a full Encounter Builder.
