# Canonical Glossary

- **World** — shared fictional setting that can contain one or more Sagas.
- **Saga** — one playable campaign/storyline within a World.
- **Desk** — default spatial working environment.
- **Board** — remembered composition/view of persistent World Objects plus Board-only material.
- **Canvas** — spatial presentation surface; never the source of world identity/truth.
- **World Object** — persistent fictional identity: Character, Place, Faction, Artifact, Thread, Event, Source, or Fragment.
- **Projection** — surface/task-specific representation of the same identity.
- **Focus** — deliberate deep-object workspace.
- **Prepare** — Session planning workspace.
- **Stage** — live Session workspace on the web.
- **Settlement** — post-Session reconstruction/review/commit workflow.
- **Chronicle** — temporal workspace/lens over story-valid history.
- **Librarian** — persistent AI operating layer; agentic only within human-authorized work.
- **Fragment** — durable low-friction unclassified capture.
- **Relationship** — first-class semantic Subject → Predicate → Object data; not a decorative Canvas connector.
- **Session Instance** — Session-scoped runnable identity that is not yet persistent world identity.
- **Change Set** — one conceptual semantic change transaction/group; may contain Story Changes and atomic mutations.
- **Story Position** — semantic position in fiction chronology, independent from edit timestamp.
- **Pencil / Ink** — content maturity, not truth/canon.
- **Proposed / Pending / Settled** — authority/truth workflow states, distinct from maturity.
- **Publication** — explicit visibility grant/artifact for players; separate from settled truth.
