# MEC-015 — Rules Reference Binding

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Links a mechanics value/action/spell/ability/template section directly to the GM's rules material.

## Reference targets

Uploaded rules PDF, exact page, document anchor, web URL, Source excerpt, or campaign house-rules Source.

## Behaviour

A compact reference affordance can open Source Peek/Viewer, exact PDF page, web reference, or Librarian with that Source in context.

## Relationships

- [[DSK-033 — Pinned Reference Shelf]]
- [[OBJ-SRC — Source Representation Family]]
- Search
- Librarian retrieval

## Handoff

Build **MEC-015 — Rules Reference Binding** as the deep-link between mechanics and user-owned/reference Source material.
