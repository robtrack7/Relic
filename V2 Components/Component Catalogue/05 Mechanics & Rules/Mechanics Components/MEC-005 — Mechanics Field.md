# MEC-005 — Mechanics Field

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Smallest reusable labelled mechanics value.

## Form & behaviour

Supports text, number, signed modifier, enum, checkbox, rating, formula result, short text, object/reference, and dice expression. Supports read/edit, validation, optional derivation, and optional Rules Reference.
