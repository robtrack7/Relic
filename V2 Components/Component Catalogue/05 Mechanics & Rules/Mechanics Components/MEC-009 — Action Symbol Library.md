# MEC-009 — Action Symbol Library

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Per-system visual token packs for action economies and mechanical shorthand.

## Examples

D&D-like: Action / Bonus Action / Reaction / Move through compact labels/safe glyphs. Pathfinder: one/two/three-action, reaction, free-action semantics. Other systems can supply custom timing/resource/narrative-dice marks.

## Licensing & safety

Internal semantic types are independent of proprietary artwork. Official glyphs are used only where permitted. Text fallbacks are mandatory. Custom templates may use user-owned/imported icon assets through safe handling.

## Handoff

Build **MEC-009 — Action Symbol Library** as the pluggable visual-token mapping for system action economies.
