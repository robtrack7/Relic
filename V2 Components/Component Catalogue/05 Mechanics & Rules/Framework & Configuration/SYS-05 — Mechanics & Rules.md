# SYS-05 — Mechanics & Rules

Relic mechanics use one modular engine with curated first-party templates and GM-created/derived templates. Character Focus remains designed by Relic; only the mechanics block is initially customizable.

## Core model
`Mechanics Framework → Template Definition → Object Mechanics Data → Presentation Profile → Renderer`

## Principles
- Do not hard-code D&D as universal.
- Do not force every GM to build a sheet from scratch.
- Support custom action economies, rich dice models, and non-ranked encounter-flow models.
- Support optional Session-scoped live resources without automatic spending or combat adjudication.
- Encounter Flow is template-defined and Stage-owned when used; it may be ranked, spotlight, alternating, phased, or freeform.
- Rules PDFs/web references are Sources and can be linked directly to mechanics.
- No automated combat engine or rule adjudication.
