# MEC-020 — Rules Reference Source Model

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Defines how Relic can act as a personal rules workspace without requiring a bundled proprietary rules compendium.

## Supported material

Rules material is Source content: uploaded PDF, web link, plaintext/Markdown, or GM-authored house rules.

## Use

Rules Sources can be indexed, searched, cited by Librarian, placed on a Board, pinned to [[DSK-033 — Pinned Reference Shelf]], and linked from mechanics fields/actions.

## Behaviour

Where possible, bindings deep-link to exact PDF pages, document anchors, excerpts, or URLs. Librarian can answer rules questions using authorized Sources in context.

## Boundaries

Hosting user-provided/reference material is separate from Relic redistributing complete commercial rules. Template/source packaging must respect applicable licenses.

## Handoff

Use **MEC-020 — Rules Reference Source Model** as the product model for mechanics-linked rules PDFs, webpages, and house-rules Sources.
