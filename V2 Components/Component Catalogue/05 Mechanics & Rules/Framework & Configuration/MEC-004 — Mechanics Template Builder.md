# MEC-004 — Mechanics Template Builder

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Allows GMs to create/modify mechanics templates for unsupported systems, house rules, or preferred stat-block layouts.

## Context & placement

A Settings/design utility, not ordinary Character editing.

## Use

Start blank or clone a first-party template; add modules; drag/reorder sections; snap into constrained columns; configure fields/resources/action tokens; set initiative; choose visibility; preview Summary/Card Back/Focus/Encounter Reference.

## Layout model

Constrained responsive grid rather than arbitrary absolute-position design. Modules use supported full/half/third-width or compact row arrangements.

## Boundaries

Customizes the mechanics block only. It does not initially redesign Character identity, narrative, Roleplay, Relationships, Knowledge, History, or full Focus shell. No arbitrary CSS or executable user code.

## Handoff

Build **MEC-004 — Mechanics Template Builder** as the constrained modular layout editor for custom/derived stat blocks.
