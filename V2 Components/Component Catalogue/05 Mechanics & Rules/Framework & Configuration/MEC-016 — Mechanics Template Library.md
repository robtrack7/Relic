# MEC-016 — Mechanics Template Library

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Catalogues first-party and user mechanics templates.

## Categories

Relic templates; user templates created/cloned through Builder; future community/import templates only if later warranted.

## Initial template targets

D&D 5e/2024, Pathfinder 2e, Daggerheart, Cosmere RPG, Cyberpunk RED, Star Wars narrative dice, Generic d20, Generic Percentile, Generic Dice Pool, Custom Blank.

## Anatomy

Template entry shows system/profile name, supported roles, version, preview, source/license note where relevant, and Clone & Customize.

## Handoff

Build **MEC-016 — Mechanics Template Library** as the catalogue/selection surface for first-party and user templates.
