# MEC-002 — Mechanics Template Definition

Parent: [[SYS-05 — Mechanics & Rules]]

## Purpose

Versioned declarative mechanics template definition without arbitrary executable template code.

## Inputs / structure

May declare system/template identity/version, role variants, dice model, action economy, sections/modules, fields/stable IDs, formulas, resource tracks/live-resource declarations, action lists, skill groups, spell/power groups, attack groups, encounter-flow strategy, symbol pack, layout profiles, and Rules Reference slots.

## Important behaviour

Defines/derives Summary, Expanded Back, Full Focus, and Encounter Reference profiles. Updates must not silently discard existing mechanics data.

## Handoff

Implement **MEC-002 — Mechanics Template Definition** as the versioned declarative schema underlying every mechanics template.
