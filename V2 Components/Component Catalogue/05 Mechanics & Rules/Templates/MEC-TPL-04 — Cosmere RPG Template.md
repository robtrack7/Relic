# MEC-TPL-04 — Cosmere RPG Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Extensible Cosmere RPG structural template rather than generic D&D.

## Core modules / concerns

d20-based checks, Plot Die support, skills, defenses, talents, talent-tree abilities, setting/magic-system powers, resources, weapons, and system-specific Character fields.

## System-specific behaviour

Stormlight, Mistborn, and future Cosmere lines should use template variants/modules when practical rather than separate Character UI families.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-04 — Cosmere RPG Template** as a first-party mechanics template using the shared Mechanics Framework.
