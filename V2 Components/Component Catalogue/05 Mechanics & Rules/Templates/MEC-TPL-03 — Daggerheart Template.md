# MEC-TPL-03 — Daggerheart Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Daggerheart-compatible layout reflecting distinct dice, resource, threshold, and card/ability structure.

## Core modules / concerns

Traits, Experiences, Duality Dice, Evasion, Armor, damage thresholds, HP, Stress, Hope, Proficiency, weapons, Domain abilities/cards, ancestry/community/subclass material, actions/abilities, reaction material.

## System-specific behaviour

Supports Hope/Fear Duality Dice without flattening distinct dice into a generic sum-only model. Uses a Spotlight-style Encounter Flow instead of forcing ranked initiative where the system does not use it. Participant and GM/Session-scoped live resources are declared separately through the shared live-resource model.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-03 — Daggerheart Template** as a first-party mechanics template using the shared Mechanics Framework.
