# MEC-TPL-05 — Cyberpunk RED Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Cyberpunk RED-compatible layout around STAT + Skill + d10 structure.

## Core modules / concerns

INT, REF, DEX, TECH, COOL, WILL, MOVE, BODY, EMP; Role/Role Ability; skills; HP; armor; Humanity; Reputation; Luck; weapons; cyberware; initiative; attacks.

## System-specific behaviour

Initiative supports REF + d10 style strategy. Action presentation reflects Cyberpunk's own move/action structure.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-05 — Cyberpunk RED Template** as a first-party mechanics template using the shared Mechanics Framework.
