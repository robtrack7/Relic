# MEC-TPL-02 — Pathfinder 2e Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Pathfinder 2e Character/creature mechanics with its distinct action economy, proficiency structure, and flexible initiative.

## Core modules / concerns

Level, attributes, Perception, defenses, saves, HP, Speed, skills/proficiency, attacks, actions, reactions, free actions, spells, traits, resources, conditions.

## System-specific behaviour

Supports 1/2/3 Action, Reaction, Free Action semantics. Initiative can use Perception or another applicable skill/check. Official-style glyphs only where permitted; safe fallbacks required.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-02 — Pathfinder 2e Template** as a first-party mechanics template using the shared Mechanics Framework.
