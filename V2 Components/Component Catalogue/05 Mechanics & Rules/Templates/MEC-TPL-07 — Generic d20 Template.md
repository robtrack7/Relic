# MEC-TPL-07 — Generic d20 Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Clean foundation for unsupported/homebrew d20 systems.

## Core modules / concerns

Attributes, modifiers, defenses, health, saves, skills, actions, attacks, powers, resources, configurable d20 initiative.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-07 — Generic d20 Template** as a first-party mechanics template using the shared Mechanics Framework.
