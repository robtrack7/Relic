# MEC-TPL-01 — D&D 5e & 2024 Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

D&D-compatible Character/adversary mechanics layout using the shared engine.

## Core modules / concerns

Level, ability scores/modifiers, proficiency, saves, skills, AC, HP, Speed, Initiative, senses, attacks, Actions, Bonus Actions, Reactions, spells, features, resources, conditions, equipment. Adversary role can use compact monster/stat-block arrangement.

## System-specific behaviour

Action pack supports Action, Bonus Action, Reaction, movement, and other labelled timing. Do not imitate Pathfinder's action glyph model.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-01 — D&D 5e & 2024 Template** as a first-party mechanics template using the shared Mechanics Framework.
