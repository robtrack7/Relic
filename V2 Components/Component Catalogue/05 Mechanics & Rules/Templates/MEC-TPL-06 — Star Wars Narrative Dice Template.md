# MEC-TPL-06 — Star Wars Narrative Dice Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Proves support for symbolic narrative dice rather than only numbered polyhedrals.

## Core modules / concerns

Characteristics, skills, wounds, strain, soak/defense, talents, weapons, Force/campaign-line resources, custom narrative dice pools, and symbolic outcomes.

## System-specific behaviour

Requires configurable symbolic dice model. Proprietary symbols/content require appropriate licensing or user-provided assets; safe fallbacks must exist.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-06 — Star Wars Narrative Dice Template** as a first-party mechanics template using the shared Mechanics Framework.
