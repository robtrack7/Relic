# MEC-TPL-10 — Custom Blank Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Durable fallback for obscure systems, homebrew games, house rules, and future games without a first-party template.

## Core modules / concerns

Starts without system assumptions; GM adds fields, resources, skills, actions, powers, dice expressions, Encounter Flow definitions, symbols, and layout sections through Builder.

## System-specific behaviour

Still inherits Relic's safe constrained responsive module/layout system.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-10 — Custom Blank Template** as a first-party mechanics template using the shared Mechanics Framework.
