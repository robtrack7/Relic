# MEC-TPL-09 — Generic Dice Pool Template

Parent: [[MEC-016 — Mechanics Template Library]]

## Purpose

Configurable foundation for games built from dice pools rather than one die + modifier.

## Core modules / concerns

Configurable die size, pool source, target number, success counting, exploding dice, advantage/penalty dice, resources, attacks/actions, derived pool formulas.

## Layout profiles

Define at least Summary, Expanded Back, Full Focus, and Encounter Reference using shared mechanics components.

## Rules boundary

Defines structure/presentation and references; does not bundle a full commercial rules compendium or automate rule adjudication.

## Handoff

Build **MEC-TPL-09 — Generic Dice Pool Template** as a first-party mechanics template using the shared Mechanics Framework.
