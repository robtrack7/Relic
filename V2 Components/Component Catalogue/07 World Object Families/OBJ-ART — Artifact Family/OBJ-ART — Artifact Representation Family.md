# OBJ-ART — Artifact Representation Family

Parent: [[SYS-07 — World Object Families]]

## Purpose

Defines the complete UI family for significant fictional objects: relics, weapons, magic items, books, documents, keys, vehicles, crowns, devices, heirlooms, and important mundane objects that deserve persistent identity.

## Family emphasis

Artifact representations prioritize:
- visual identity;
- what the object is;
- narrative importance;
- holder/location;
- mechanics where applicable;
- provenance/history;
- active Threads and Events.

Not every item becomes an Artifact. Only campaign-significant objects need persistent Artifact identity.
