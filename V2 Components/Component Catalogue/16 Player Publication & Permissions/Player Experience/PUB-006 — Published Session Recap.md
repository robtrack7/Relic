# PUB-006 — Published Session Recap

Parent: [[SYS-16 — Player Publication & Permissions]]

## Purpose

Turns the settled Session recap into an optional player-facing publication artifact without conflating recap text with structured world canon.

## Source

Start from the accepted Session recap produced by [[REV-012 — Recap & Prep Implications]].

## Player-safe editing

The GM may edit/simplify the player version before publication.

This allows spoiler-safe presentation without rewriting the underlying Session or structured Story Changes.

## Artifact semantics

A published Session recap is versioned/frozen publication content.

Later edits create a new publication version rather than silently changing what was historically published without trace.

## Not canon mutation

Publishing or editing the player recap does not itself change World Object state.

## Handoff

Implement as a publication artifact linked back to the Session and settled recap when player features are prioritized.
