# LIB-001 — Library Surface

Parent: [[SYS-09 — Search & Library]]

## Purpose

Provides the systematic index into the active world.

Library answers:

> What knowledge/material exists in this Saga and World?

It complements Desk rather than replacing it.

## Context & placement

Library is one of Relic's durable high-level destinations alongside Desk and Sessions.

Global App Shell controls remain available:
- Current Context;
- Global Search;
- Active Session Return;
- Librarian;
- Profile.

## Content domains

Library includes:

**World Objects**
- Characters
- Places
- Factions
- Artifacts
- Threads
- Events
- Fragments

**Sources**
- PDFs
- transcripts
- webpages
- notes/documents
- images
- rules references

Library does not become a browser for every persistence table.

## Explicit exclusions

Boards are primarily browsed through Desk/Board context.

Sessions have their own durable Sessions destination.

Both remain globally searchable.

This keeps Library focused on world knowledge/reference material.

## Major content regions

- [[LIB-002 — Library Category Navigator]]
- [[LIB-004 — Library Filter Bar]]
- [[LIB-003 — Library Index Collection]]

Avoid a giant hero/dashboard region.

## Appearance & behaviour

Systematic and calm.

More archival/catalogue-like than Desk, but still editorial rather than database-administrative.

The GM should be able to scan large collections without losing the warmth of the Relic visual system.

## Responsive behaviour

Wide layouts can use a narrow Library-only category rail.

Narrow layouts collapse category navigation into a compact selector.

Collection remains primary.
