# OBJ-005 — Object Type Cue

Parent: [[OBJ-001 — World Object Representation Framework]]

## Purpose

Provides a restrained and consistent indication of broad World Object family when type recognition helps the GM interpret a compact representation.

## Use

May distinguish Character, Place, Faction, Artifact, Thread, Event, Source, and Fragment.

Large or visually self-evident projections do not need a permanent explicit type label simply because the data has a type.

## Anatomy

Use one or a combination of:

- small family icon;
- short type label;
- restrained typographic treatment.

Avoid turning type into a large coloured badge system.

## Appearance & behaviour

Type is secondary to fictional identity.

The cue must remain legible without relying only on colour. Compact Search/Library projections may use it more explicitly than Focus surfaces.

## Relationships

- [[OBJ-004 — Object Identity Lockup]] — common host.
- Search/Library projections — frequent consumers.
- family-specific projections — opt in only where useful.

## Handoff

Build **OBJ-005 — Object Type Cue** as the quiet shared family indicator for compact or otherwise ambiguous World Object representations.
