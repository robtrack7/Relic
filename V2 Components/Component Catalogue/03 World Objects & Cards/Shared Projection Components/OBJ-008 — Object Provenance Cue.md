# OBJ-008 — Object Provenance Cue

Parent: [[OBJ-001 — World Object Representation Framework]]

## Purpose

Provides a compact indication that useful source/provenance exists behind an object or visible piece of derived material without turning every projection into an audit interface.

## Use

Especially useful when material is tied to:

- a Session;
- transcript evidence;
- imported notes/documents;
- GM-authored source material;
- Librarian-derived material;
- multiple supporting Sources.

Surface it when provenance helps the GM judge or retrace the material, not merely because provenance exists technically.

## Anatomy

Possible compact forms:

- source mark/icon;
- source count;
- `from Session 12`;
- short origin label.

Activation deepens to the relevant Sources & Provenance view rather than expanding a citation list inside the card.

## Appearance & behaviour

Secondary metadata with very low visual weight.

Avoid omnipresent authorship avatars, provider labels, or AI badges. The objective is confidence and traceability on demand.

## Relationships

- Sources & Provenance Focus Block — detailed origin/evidence presentation.
- Source representation family — persistent Source identities.
- Review/Librarian outputs — frequent provenance consumers.

## Data / utility relationship

Reads authorized provenance/source relationships. It does not determine truth, visibility, or authorship policy.

## Handoff

Build **OBJ-008 — Object Provenance Cue** as the compact, selectively visible entry into a World Object's supporting origin and evidence.
