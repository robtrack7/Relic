# SYS-03 — World Objects & Cards

World Objects are persistent fictional identities whose narratively meaningful state can change over story time and whose presentation changes by surface, task, disclosure, and spatial scale.

This folder owns the shared representation framework and World Object family routers. Family-specific projections are authored in follow-on sections.

## Core rules

- One identity can appear in many separately coded projections.
- Projection is not identity.
- Board Placement is not identity.
- Maturity is not truth.
- Historical/as-of projection is the same identity at another story position.
- Rich families do not share one universal `EntityCard`.
- Separate representations become separate components when anatomy/layout/role materially differ.
- Not every family needs every representation role.
